# TIWIGO

Live TV guide and player for free-to-air Georgian, Armenian and Russian channels.

- Web app: https://grishanazaretyan.github.io/tiwigo/
- IPTV playlist for apps such as OttPlayer or TiviMate: https://grishanazaretyan.github.io/tiwigo/playlist.m3u

Channel list from the public iptv-org project. Programme guide from epg.pw.
